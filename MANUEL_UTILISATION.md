# Manuel d'utilisation de l'application Dr. Tchuifon

Ce manuel est conçu pour un utilisateur final qui ne connaît rien à la programmation. Il explique pas à pas comment utiliser chaque fonctionnalité de l'application, où cliquer, et ce qu'il faut faire.

---

## 1. Présentation générale

L'application est un site web professionnel pour présenter :

- les publications scientifiques,
- les cours,
- les encadrements (thèses, master, doctorat),
- les collaborateurs et partenaires,
- un formulaire de contact.

Il existe deux types d'accès :

- un accès public pour consulter les pages et le contenu,
- un accès protégé pour se connecter et gérer des informations personnelles,
- un accès administrateur pour modifier le contenu du site.

---

## 2. Navigation principale

### 2.1 Barre de menu

Sur toutes les pages publiques, la barre de menu en haut permet d'accéder rapidement à :

- `Accueil`
- `Publications`
- `Cours`
- `Encadrements`
- `Collaborateurs`
- `Recherche`
- `Contact`

### 2.2 Se connecter

Si vous n'êtes pas connecté, un bouton `Se connecter` apparaît dans la barre de menu.

1. Cliquez sur `Se connecter`.
2. Entrez votre email et votre mot de passe.
3. Cliquez sur `Connexion`.

Une fois connecté, un menu utilisateur apparaît à la place du bouton.

### 2.3 Menu utilisateur

Quand vous êtes connecté, cliquez sur l'icône ou le nom en haut à droite pour ouvrir le menu utilisateur.

À l'intérieur, vous trouverez :

- `Mon Profil`
- `Dashboard Admin` (si vous êtes administrateur)
- `Mon Espace` (si vous êtes collaborateur)
- `Déconnexion`

---

## 3. Page d'accueil

La page d'accueil présente :

- la photo et le profil de Dr. Tchuifon,
- des informations générales sur l'étude et l'institution,
- des boutons rapides pour accéder aux publications et au contact.

### Comment l'utiliser

1. Cliquez sur `Publications` pour voir la liste complète des publications.
2. Cliquez sur `Me contacter` pour ouvrir le formulaire de contact.
3. Utilisez le menu en haut pour accéder à d'autres sections.

---

## 4. Page Publications

Cette page liste toutes les publications scientifiques.

### Fonctionnalités disponibles

- Recherche par titre ou par auteur.
- Filtrer par type de publication : articles, conférences, chapitres de livre, thèses, brevets, posters.
- Accès au détail de chaque publication.

### Étapes à suivre

1. Dans le champ `Rechercher par titre ou auteur...`, tapez un mot-clé.
2. Dans le menu déroulant `Tous les types`, sélectionnez le type de publication souhaité.
3. Les cartes de publications affichées se mettent à jour automatiquement.
4. Cliquez sur une publication pour voir sa page de détails.

---

## 5. Page Cours

Cette page présente les cours disponibles.

### Ce que vous pouvez faire

- Lire la liste des cours.
- Cliquer sur un cours pour voir ses détails.

### Étapes à suivre

1. Allez dans le menu en haut et cliquez sur `Cours`.
2. Faites défiler la liste des cours.
3. Cliquez sur un cours pour ouvrir la fiche détaillée.

---

## 6. Page Encadrements

La page `Encadrements` montre les thèses, mémoires et projets encadrés.

### Ce que vous pouvez faire

- Voir la liste des encadrements.
- Cliquer sur un encadrement pour lire la description complète.

### Étapes à suivre

1. Cliquez sur `Encadrements` dans le menu principal.
2. Parcourez les encadrements visibles à l'écran.
3. Cliquez sur un encadrement pour accéder à la page de détail.

---

## 7. Page Collaborateurs

La page `Collaborateurs` présente les personnes ou institutions partenaires.

### Ce que vous pouvez faire

- Consulter la liste des collaborateurs.
- Cliquer sur un collaborateur pour voir son profil.

### Étapes à suivre

1. Cliquez sur `Collaborateurs` dans le menu principal.
2. Cherchez un collaborateur par son nom ou son institution.
3. Cliquez sur le nom ou la carte pour ouvrir la fiche détaillée.

---

## 8. Page Recherche

La page `Recherche` centralise les recherches pour trois catégories :

- `Encadrements`
- `Publications`
- `Collaborations`

### Fonctionnalités disponibles

- Recherche par mot-clé.
- Changement d'onglet pour sélectionner la catégorie.
- Filtre de niveau pour les encadrements.

### Étapes à suivre

1. Entrez un mot-clé dans le champ `Rechercher par mot-clé...`.
2. Cliquez sur l’onglet souhaité : `Encadrements`, `Publications`, ou `Collaborations`.
3. Pour les encadrements, choisissez un niveau si nécessaire : `Tous niveaux`, `Ingénieur`, `Master 2`, `Doctorat`, `Post-doc`.
4. Les résultats s’affichent automatiquement.

---

## 9. Page Contact

Cette page contient un formulaire de contact.

### Ce que vous pouvez faire

- Envoyer un message à l’équipe.
- Indiquer votre nom, votre email et votre message.

### Étapes à suivre

1. Cliquez sur `Contact` dans le menu principal.
2. Remplissez les champs : nom, email, sujet et message.
3. Cliquez sur `Envoyer`.
4. Attendez la confirmation que votre message a bien été envoyé.

---

## 10. Authentification et profil utilisateur

### 10.1 Se connecter

1. Cliquez sur `Se connecter`.
2. Saisissez votre email.
3. Saisissez votre mot de passe.
4. Cliquez sur `Connexion`.

### 10.2 S'inscrire

1. Cliquez sur `S'inscrire` si l’écran est disponible.
2. Entrez un email valide et un mot de passe.
3. Cliquez sur `Créer un compte`.
4. Vérifiez votre email si une confirmation est demandée.

### 10.3 Mot de passe oublié

1. Sur la page de connexion, cliquez sur `Mot de passe oublié`.
2. Entrez votre email.
3. Validez pour recevoir un lien par email.
4. Suivez le lien pour choisir un nouveau mot de passe.

### 10.4 Vérifier l'email

1. Si votre compte demande une vérification, suivez le lien envoyé par email.
2. Après vérification, revenez sur le site et connectez-vous.

### 10.5 Mon Profil

La page `Mon Profil` permet de gérer vos informations personnelles.

#### Actions possibles

- Modifier votre nom complet.
- Mettre à jour votre email.
- Modifier votre photo de profil.
- Changer votre mot de passe.

#### Étapes pour modifier le profil

1. Cliquez sur `Mon Profil` dans le menu utilisateur.
2. Cliquez sur `Modifier le profil`.
3. Modifiez le champ `Nom complet` ou `Email`.
4. Pour changer la photo, cliquez sur l'icône de caméra et sélectionnez une image.
5. Cliquez sur `Enregistrer` ou sur le bouton de validation.

#### Contraintes de mot de passe

- Le mot de passe doit avoir au moins 8 caractères.
- Il doit contenir des lettres minuscules, des lettres majuscules et des chiffres.
- Le champ `Confirmation du mot de passe` doit être identique au nouveau mot de passe.

---

## 11. Espace administrateur

### 11.1 Accès admin

Seuls les comptes avec le rôle `ADMIN` peuvent accéder aux pages suivantes :

- `Dashboard`
- `Gestion du profil`
- `Publications`
- `Cours`
- `Encadrements`
- `Collaborateurs`
- `Messages`

### 11.2 Tableau de bord (`Dashboard`)

Le tableau de bord montre :

- les statistiques principales,
- des liens rapides vers les sections de gestion.

### 11.3 Gestion des publications

Sur la page `Publications`, l’administrateur peut :

- ajouter une nouvelle publication,
- modifier une publication existante,
- supprimer une publication.

#### Étapes pour ajouter une publication

1. Cliquez sur `Publications` dans le menu latéral admin.
2. Cliquez sur le bouton `Nouveau` ou `Ajouter une publication`.
3. Remplissez les champs : titre, auteurs, type, année, résumé, etc.
4. Enregistrez la publication.

#### Étapes pour modifier une publication

1. Cliquez sur l’icône `Modifier` (souvent un crayon) à droite de la publication.
2. Changez les informations souhaitées.
3. Cliquez sur `Enregistrer`.

#### Étapes pour supprimer une publication

1. Cliquez sur l’icône `Supprimer` (souvent une poubelle).
2. Confirmez la suppression dans la boîte de dialogue.

### 11.4 Gestion des cours

Sur la page `Cours`, l’administrateur peut :

- créer un nouveau cours,
- modifier un cours existant,
- supprimer un cours.

### 11.5 Gestion des encadrements

Sur la page `Encadrements`, l’administrateur peut :

- ajouter un nouvel encadrement,
- modifier un encadrement,
- supprimer un encadrement.

### 11.6 Gestion des collaborateurs

Sur la page `Collaborateurs`, l’administrateur peut :

- ajouter un nouveau collaborateur,
- modifier un collaborateur,
- supprimer un collaborateur.

#### Étapes courantes

1. Cliquez sur `Collaborateurs` dans la colonne de gauche.
2. Utilisez le bouton `Nouveau Collaborateur`.
3. Remplissez les informations : nom, institution, pays, domaine.
4. Sauvegardez.
5. Pour modifier, cliquez sur l’icône crayon.
6. Pour supprimer, cliquez sur l’icône corbeille et confirmez.

### 11.7 Gestion des messages

Sur la page `Messages`, l’administrateur peut :

- lire les messages reçus via le formulaire contact,
- supprimer ou marquer les messages comme traités.

### 11.8 Gestion du profil admin

La page `Profil` dans l’interface admin permet de modifier :

- le nom complet,
- le titre,
- la biographie,
- l’institution,
- le département,
- l’email,
- le téléphone,
- la localisation de bureau,
- les spécialités,
- les diplômes,
- les liens Google Scholar, ResearchGate, ORCID, LinkedIn, site web.

#### Étapes pour modifier le profil admin

1. Cliquez sur `Profil` dans le menu admin.
2. Cliquez sur `Modifier`.
3. Modifiez les champs nécessaires.
4. Cliquez sur `Enregistrer`.

### 11.9 Contraintes à respecter pour l'administration

- Vous devez être connecté avec un compte admin.
- Les champs obligatoires ne doivent pas être laissés vides.
- Les URLs doivent être valides lorsqu'elles sont demandées.
- La photo de profil doit être au format image et ne pas dépasser 5 MB.
- Pour les mots de passe, respectez la longueur et les règles de complexité.
- La suppression est définitive : vérifiez avant de valider.

---

## 12. Bonnes pratiques pour l’utilisateur final

- Vérifiez toujours votre email si la connexion ou l'inscription échoue.
- Utilisez un mot de passe facile à retenir, mais sécurisé.
- Si une page affiche un message d'erreur, relisez les champs remplis.
- Pour tout contact, utilisez le formulaire de la page `Contact`.

---

## 13. En résumé

### Utilisation courante

1. Ouvrez l'application.
2. Utilisez la barre de menu pour naviguer entre les sections.
3. Pour trouver rapidement une publication ou un encadrement, utilisez la page `Recherche`.
4. Pour envoyer un message, allez sur `Contact`.
5. Si vous êtes administrateur, utilisez le menu `Dashboard` et les pages de gestion.

### Fonctions principales

- `Publications` : consulter et filtrer les publications.
- `Cours` : lire les descriptions des cours.
- `Encadrements` : voir les projets et thèses encadrés.
- `Collaborateurs` : connaître les partenaires.
- `Recherche` : chercher dans plusieurs catégories.
- `Contact` : envoyer un message.
- `Mon Profil` : mettre à jour vos informations personnelles.
- `Admin` : gérer le contenu du site.
